# 快速开始

## 环境要求

- Node.js >= 18
- npm >= 9

## 安装与运行

```bash
# 1. 克隆仓库
git clone https://gitcode.com/bingochou/vue-admin-system.git

# 2. 进入项目目录
cd vue-admin-system

# 3. 安装依赖
npm install

# 4. 启动开发服务器
npm run dev
```

## 访问系统

启动后在浏览器中访问 `http://localhost:3000`

### 登录凭据

| 字段 | 值 |
|------|-----|
| 用户名 | admin |
| 密码 | admin123 |

## 构建生产版本

```bash
npm run build
```

构建产物在 `dist/` 目录下。

## 项目结构

```
vue-admin-system/
├── package.json          # 项目配置
├── vite.config.js        # Vite 配置
├── index.html            # 入口 HTML
└── src/
    ├── main.js           # 应用入口
    ├── App.vue           # 根组件
    ├── router/           # 路由配置
    ├── store/            # Pinia 状态管理
    ├── layout/           # 布局组件
    │   ├── index.vue
    │   └── components/
    │       ├── Sidebar.vue
    │       └── Header.vue
    └── views/            # 页面视图
        ├── login/        # 登录页
        ├── home/         # 首页
        ├── system/       # 系统管理
        └── tools/        # 系统工具
```
