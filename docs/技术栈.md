# 技术栈说明

## 核心技术

### Vue 3
- 使用 Composition API（`<script setup>` 语法）
- 响应式数据管理
- 组件化开发

### Vite
- 下一代前端构建工具
- 极速冷启动
- 即时热模块替换（HMR）

### Element Plus
- Vue 3 UI 组件库
- 提供表单、表格、菜单、布局等组件
- 主题可定制

### Vue Router
- 官方路由管理器
- 支持嵌套路由
- 路由守卫（登录拦截）

### Pinia
- Vue 3 官方状态管理库
- 管理用户登录状态
- 支持 localStorage 持久化
